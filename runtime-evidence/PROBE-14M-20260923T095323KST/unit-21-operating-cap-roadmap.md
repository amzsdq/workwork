# Unit 21 — Operating-cap roadmap

Probe: PROBE-14M-20260923T095323KST

Once the first credible upper boundary is bracketed/refined:
1. choose a candidate below that boundary with explicit margin;
2. collect >=5 eligible clean closes at/near it;
3. include retrospective wake evidence where measurable;
4. replicate near the candidate across representative workload profiles;
5. estimate close reserve from repeated direct observations;
6. only then compare P1-P4 admission policies and planned-gap reductions;
7. activate rollback monitoring after promotion.

This ordering keeps the current coarse search focused on the actual unknown: the runtime ceiling.
