# Unit 13 — Cross-profile validation audit

Probe: PROBE-14M-20260923T095323KST

Coarse rotation intentionally changes workload shape at each target, which is efficient for discovering obvious profile sensitivity but cannot establish a universal cap. Once a candidate boundary/cap is found, at minimum MIXED_IO, MICRO_UNIT_CHAIN, and REASONING_HEAVY or LARGE_UNIT must be replicated near the candidate.

Therefore a clean 14m W3 result, if achieved, supports only the 14m observed lower bound and next coarse probe; it does not establish 14m safety across profiles.
